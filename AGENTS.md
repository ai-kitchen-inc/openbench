# AGENTS.md

Guidance for AI coding agents (Codex, Cursor, etc.) working in this repository.

**The canonical agent guidance lives in [CLAUDE.md](CLAUDE.md).** It is the single
source of truth for architecture, conventions, code-quality rules, project structure,
and skills. Read it before making changes.

This file previously duplicated CLAUDE.md in full; the two had drifted. To keep one
source of truth, AGENTS.md now points to CLAUDE.md instead of forking it. Everything in
CLAUDE.md applies regardless of which agent you are — substitute your own tool name
wherever it says "Claude Code".
