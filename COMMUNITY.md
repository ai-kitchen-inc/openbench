# Community

Welcome to the OpenBench community! Whether you are here to ask a question,
report a bug, or land your first pull request, this page points you to the
right place.

## Start here

- **New to the project?** Read [Getting Started](docs/GETTING_STARTED.md).
- **Want to contribute?** Read [CONTRIBUTING.md](CONTRIBUTING.md).
- **Need help?** See [SUPPORT.md](SUPPORT.md).
- **Found a security issue?** See [SECURITY.md](SECURITY.md).
- **How decisions are made?** See [GOVERNANCE.md](GOVERNANCE.md).

## Your first contribution

1. Look for issues labeled **`good first issue`** and **`help wanted`**.
2. Comment on the issue to claim it.
3. Follow the [development workflow](CONTRIBUTING.md#development-workflow).
4. Open a pull request using the
   [PR template](.github/PULL_REQUEST_TEMPLATE.md).

Every contribution counts — code, docs, tests, triage, and reviews are all
valued. See [CONTRIBUTING.md](CONTRIBUTING.md) for the details.
