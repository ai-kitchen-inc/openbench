# proper-2025

Knowledge about Indonesia's PROPER 2025 environmental rating program
(Peringkat Kinerja Perusahaan dalam Pengelolaan Lingkungan) and what it
expects from companies submitting Life Cycle Assessment reports.

## Triggers
- User asks about PROPER 2025 criteria, tiers, or submission requirements
- User mentions Biru, Merah, Hitam, Hijau, or Emas ratings
- User asks how LCA ties into regulatory compliance
- User references KLHK (Kementerian Lingkungan Hidup dan Kehutanan)

## Dependencies
- None (knowledge-only skill — contributes context, no tools)
