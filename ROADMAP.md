# Roadmap

This roadmap captures the planned direction for OpenBench. It is a living
document — dates and priorities may shift based on community feedback. For the
authoritative, fine-grained backlog, see the
[issue tracker](https://github.com/ai-kitchen-inc/openbench/issues) and
[GitHub Discussions](https://github.com/ai-kitchen-inc/openbench/discussions).

## Status legend

- ✅ Done · 🚧 In progress · 📋 Planned

## Planned milestones

- [ ] **Q1 2026** — Voice-first interface for agent interaction
- [ ] **Q2 2026** — Real-time collaborative workflows
- [ ] **Q2 2026** — Marketplace for community agents and templates
- [ ] **Q3 2026** — Edge deployment for air-gapped environments
