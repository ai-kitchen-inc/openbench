# Getting Support

Thanks for using OpenBench! This document explains where to get help. Please
do **not** use the issue tracker for general support questions — use the
channels below so the issue tracker stays focused on bugs and feature work.

## Where to ask

| I want to...                                  | Go to                                                                                  |
| --------------------------------------------- | -------------------------------------------------------------------------------------- |
| Ask a "how do I...?" question                 | [GitHub Discussions](https://github.com/ai-kitchen-inc/openbench/discussions)          |
| Report a reproducible bug                     | [GitHub Issues](https://github.com/ai-kitchen-inc/openbench/issues) (bug report)       |
| Request a feature                             | [GitHub Issues](https://github.com/ai-kitchen-inc/openbench/issues) (feature request)  |
| Report a security vulnerability               | See [SECURITY.md](SECURITY.md) — **do not** open a public issue                         |
| Chat with the community                       | [Discord](https://discord.com/users/openbench.ai)                                       |
| Search prior Q&A                              | Stack Overflow tag [`openbench`](https://stackoverflow.com/questions/tagged/openbench)  |

## Before you ask

To get a faster answer:

1. Search [existing issues](https://github.com/ai-kitchen-inc/openbench/issues)
   and [discussions](https://github.com/ai-kitchen-inc/openbench/discussions).
2. Read the [documentation](docs/) — start with
   [GETTING_STARTED.md](docs/GETTING_STARTED.md).
3. Include your OpenBench version (`openbench --version`), Python version, OS,
   and a minimal reproduction.

## Response expectations

OpenBench is a community-driven, alpha-stage project maintained on a
best-effort basis. Maintainers aim to triage new issues within **5 business
days**, but there is no guaranteed SLA. Pull requests that include a failing
test or clear reproduction are reviewed fastest.
